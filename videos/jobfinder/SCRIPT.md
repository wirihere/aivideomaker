# SCRIPT — JobFinder (Stage 4 narration)

> Per founding doc Stage 4: write the script that lands. Don't pre-target a duration. The TTS measurement in Stage 5 sets the video length.

## Awareness level (Schwartz, Stage 3 Job C)

*Most-aware / Product-aware / Solution-aware / Problem-aware / Unaware* — pick one. Hook calibrates to this.

## Framework (Stage 3 Job D)

*AIDA / PAS / PASTOR / BAB / 4 Ps / Story arc* — pick one.

## Script (Draft A)

```
<line 1 — hook, names what's already in the listener's head>

<line 2 — pulls them in, opens the loop>

<line 3 — proof / specifics>

...

<close — brand's own most distilled phrase>

<CTA — brand's actual CTA verb, never "Get Started">

<URL spoken phonetically: brand dot co dot N Z>
```

## 8-question rubric (Stage 3 self-score)

1. ☐ Hook test — first line stops scroll in 1.5s?
2. ☐ Slippery slide — each line makes the next feel necessary?
3. ☐ Specificity — 2+ concrete nouns/numbers per 10 words?
4. ☐ Brand voice — could a competitor say this exact line? (NO required)
5. ☐ Read-aloud — said each line out loud?
6. ☐ No-invention — every claim sourced from the scrape?
7. ☐ Conversational — could a real human say this at a kitchen table?
8. ☐ 12-year-old — would a 12-year-old understand every line?

Eight yeses → ship to TTS. Any no → fix that line, re-score.
