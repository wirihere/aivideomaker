## The brand — BinSparkle
NZ wheelie-bin cleaning marketplace (homeowner books, contractor cleans).
- Palette (from videos/binsparkle/tokens.css): leaf green #2f7a4d, leaf-deep #1f5b38,
  cream #faf6ee, sunny yellow #f4b942, coral #c25a35, ink #0d2218.
- Type: Bricolage Grotesque (display/headlines), Inter (body/UI).
- Tone: earnest, local, first-person, concrete — never corporate/aspirational.
- The mark: a tiled bin + a sun corner, in the green→leaf-deep and sunny gradients.

## Platform safe zones — 1080×1920 (9:16)  [repo rule R4]
- TOP 220px and BOTTOM 420px are covered by platform UI on TikTok/Reels organic.
- For ADS, the bottom zone is 484px.
- RIGHT 140px is covered by the action-button column.
- ⇒ Any text a viewer must read (headline, CTA, caption) must sit INSIDE the safe
  area: x between 0–940, y between 220–1500 (organic) or 220–1436 (ads).
- Pinterest pins (2:3) and IG feed (4:5) have no overlay UI, but text near extreme
  edges still gets cropped in-feed — keep a ~6% inner margin.

## Text & type  [repo rules R13, R8, R3]
- Caption/headline type ≥ 80px (~4.2% of 1920 frame height). Smaller fails sound-off
  mobile viewing.
- Contrast ≥ 4.5:1 against the photo behind it. Achieve with a scrim/gradient
  (the binsparkle comp already uses a bottom-up dark gradient), a pill background,
  or a stroke — never thin sans dropped onto a busy photo.
- First-3s on-screen text ≤ 30 characters, one line.
- Captions as sticker pills, animated per-phrase — not a static bottom subtitle bar.

## CTA & structure  [repo rules R5, R10, R14, R15]
- CTA lives in the y=720–1080 band (upper-center), NEVER in the bottom 25–35%.
- Beat structure: 0–3s hook → 3–8s promise → 8–24s proof/demo → 24–30s CTA.
  Target length 21–34s.
- End card: final 2.0–2.5s static, wordmark + one CTA line.
- Loop: end frame should match the start frame's colour/composition for a seamless
  replay (replays are a top distribution signal).

## Motion grammar  [repo rules R1, R2, R9, R11]
- Hook in ≤ 3s — first frame is a face / a hand / a bin mid-action, NOT a logo card.
  Hold the wordmark until ≥ 3s (≤ 1s if shown earlier).
- Cut cadence ≥ 6 cuts in seconds 0–8; a pattern interrupt every ≤ 2.5s (cut,
  push-in, text swap, colour shift). No static hold longer than 2.5s.
- Hero element (face / bin / motion) fills ≥ 60% of the frame in seconds 0–3.

## What "professional" means here (the bar)
On-brand palette, text fully inside the safe zone and ≥ 80px with proper contrast,
a real subject (an actual bin / a real clean — never a generic stock look), no
rendering glitches, motion that obeys the cut-cadence rules above. Anything that
would make a scroller keep scrolling past = a fail.
