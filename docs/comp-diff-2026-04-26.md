# Composition Diff Tool — `comp-diff.mjs`

Structural diff for two HyperFrames compositions. Compares the *shape* of two
comps — scenes, durations, tween structure, asset references, module imports,
color tokens — not the literal text. For text, `git diff` is already the right
tool. Use this when iterating "v3 vs v3.1" and you want to know whether you
accidentally added a 4th scene or doubled the tween count.

## Usage

```bash
# default — color-coded terminal report
node scripts/comp-diff.mjs <a.html> <b.html>
npm run comp:diff -- <a.html> <b.html>

# machine-readable
node scripts/comp-diff.mjs <a.html> <b.html> --json

# paste-ready markdown (PRs, LEARNINGS entries)
node scripts/comp-diff.mjs <a.html> <b.html> --md
```

## Exit codes

| Code | Meaning                                          |
| ---- | ------------------------------------------------ |
| 0    | No structural differences                        |
| 1    | Differences detected                             |
| 2    | One of the inputs is not a valid HyperFrames comp |

## Categories diffed

1. **Scenes** — clip elements matched by `id`. Reports added / removed /
   changed (where `data-start`, `data-duration`, or `data-track-index` shifts).
2. **Tweens** — `tl.to` / `tl.from` / `tl.fromTo` / `tl.set` calls in inline
   `<script>` blocks, bucketed by target selector. Reports counts and the set
   of animated properties per target.
3. **Assets** — `src` attrs from `<img>`, `<video>`, `<audio>`, `<source>`,
   plus `data-composition-src` sub-composition references.
4. **Modules / stylesheets** — `<link href>` and `<script src>` URLs.
5. **Color tokens** — `var(--name)` references inside inline `<style>` blocks.

Total duration is also flagged when comps differ by more than 0.1s.

## Sample output (cross-template)

```
$ npm run comp:diff -- compositions/templates/social-reel-15s.html \
                       compositions/templates/before-after-20s.html

Composition diff
  A: compositions/templates/social-reel-15s.html
  B: compositions/templates/before-after-20s.html

Total duration
  15s -> 20s   +5s  (mismatch >0.1s)

Scenes  (A=5, B=6)
  ~ s1  0s/3s -> 0s/7s  (dur +4s)
  ~ s2  3s/5s -> 7s/2s  (dur -3s)
  + s5  start=19s dur=1s track=1
  ...

Tweens  (A=5, B=10, +5)
  + "#s2-swipe"  count=1  props=[x]
  + "#s3-stamp"  count=1  props=[opacity,scale]
  ...
```

Red = "regressed" (more tweens, longer duration), green = "improved",
yellow = "changed".

## Constraints

- READ-ONLY — never modifies the input files.
- Zero new npm dependencies; uses Node built-ins only.
- Handles both standalone `<body>` comps and the `<template>` sub-comp wrapper
  pattern.
- Inline ANSI-color helper, no color package.
